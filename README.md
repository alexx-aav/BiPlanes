# Biplanes - Аркадная игра для Android

## Описание
Biplanes - это аркадная игра для Android, в которой вы управляете самолетом и сражаетесь с вражескими самолетами.

## Особенности
- Простое управление с помощью кнопок
- Динамичный геймплей
- Красочная графика
- Система очков и жизней
- Различные режимы игры

## Управление
- Кнопки со стрелками: перемещение самолета
- Кнопка "Огонь": стрельба
- Кнопка "Пауза": приостановка игры
- Кнопка "Назад": возврат в главное меню

## Сборка проекта
1. Клонируйте репозиторий:
   ```
   git clone https://github.com/yourusername/biplanes.git
   ```
2. Откройте проект в Android Studio
3. Соберите проект с помощью Gradle:
   ```
   ./gradlew assembleDebug
   ```
4. Установите APK на устройство:
   ```
   adb install app/build/outputs/apk/debug/app-debug.apk
   ```

## Требования
- Android 10.0 (API уровень 29) или выше
- Устройство с сенсорным экраном
